Part 2 - Introduction to JavaScript
Assignment #5, individual work

How to open
-----------
1. Extract this folder (part2).
2. Double-click index.html - it opens in any modern browser.
3. Press F12 and choose the "Console" tab BEFORE pressing any button.
4. Click the button of a task (Task 6 ... Task 12).
5. Read the result in the Console tab.

Every task prints its result with console.log(). The page itself shows only a
short confirmation that the task was started. The output is in the Console,
which is what the assignment asks for ("screenshots of the console output").

Tasks 7 and 8 use prompt(), so an input window appears first:
  - Task 7 asks for your name.
  - Task 8 asks for two numbers. The values 12 and 5 are already filled in;
    you can delete them and type your own numbers.
